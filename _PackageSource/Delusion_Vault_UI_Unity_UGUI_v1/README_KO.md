# Delusion Vault UI Unity UGUI v1

확정된 자산(금고) 탭 6차 디자인을 Unity 프로젝트에 적용하기 위한 원본 패키지입니다.

## 포함 내용

- 데이터 기반 UGUI 화면 생성 스크립트
- `Tools > Delusion > Create Vault Screen Prefab` 프리팹 생성기
- 평가액 순 정렬 및 4행 고정 뷰포트/세로 스크롤
- 보유 종목·대주주 클릭 이벤트
- V5 기업 엠블럼 40개
- 공통 사이드바·상단 상태 바·크림 카드·정적 대주주 카드 PNG
- Noto Sans KR 글꼴 원본과 라이선스
- 1920×1080 좌표 JSON과 샘플 데이터 JSON
- 확정 화면 미리보기 및 편집용 SVG

설치와 데이터 연결 방법은 `Assets/Delusion/UI/Vault/README_KO.md`에 있습니다.
